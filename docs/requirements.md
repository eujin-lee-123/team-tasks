# Team-Tasks 요건 정의서

> MVP 범위: 단일 테이블 · 기능 5개 이하 · 1일 안에 구현 가능한 분량  
> 기준 문서: `docs/personas.md`, `docs/user-stories.md`

---

## 1. 기능 요건

| ID | 이름 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | 일감 생성 | 팀장이 일감을 생성하고 제목·담당자·마감일·우선순위를 입력한다. | 높음 |
| F-02 | 일감 목록 조회 및 필터 | 전체 일감 또는 "내 일감"(담당자 = 나) 필터로 목록을 조회하고, 우선순위·마감일 기준으로 정렬한다. | 높음 |
| F-03 | 상태 변경 | 일감의 상태를 **할 일 → 진행 중 → 완료** 3단계로 전환한다. 담당자가 직접 변경할 수 있다. | 높음 |
| F-04 | 메모 입력·조회 | 일감에 메모를 작성하고, 팀장·담당자·관찰자 모두 열람할 수 있다. | 중간 |
| F-05 | 신규 할당 알림 | 일감이 자신에게 할당되면 앱 내 배지로 알림을 수신한다. | 낮음 |

### 요건 결정 사항

- **F-03** 담당자도 상태를 직접 변경할 수 있다 (팀장 전용 잠금 없음).
- **F-04** 메모는 팀 공유 댓글 방식으로 모든 역할이 열람 가능하다.
- **F-05** 알림 채널은 앱 내 배지로 한정한다 (이메일·슬랙 연동은 MVP 외).
- 우선순위 값은 팀장이 일감 생성·수정 시 지정한다.
- 완료된 일감은 당일 목록에 표시되며, 이후 정책은 MVP 이후에 결정한다.

## 2. 비기능 요건

### 성능 (Performance)

| 항목 | 기준값 |
|------|--------|
| 일감 목록 API 응답 시간 | p95 ≤ 300 ms |
| 페이지 최초 콘텐츠 렌더링 (LCP) | ≤ 2.5 초 |

### 보안 (Security)

| 항목 | 기준값 |
|------|--------|
| 미인증 API 접근 차단 | 인증 토큰 없는 요청에 HTTP 401 반환율 100 % |
| XSS·CSRF 방어 | OWASP Top 10 A03·A01 자동화 스캔 통과 |

### 가용성 (Availability)

| 항목 | 기준값 |
|------|--------|
| 월간 서비스 가동률 | ≥ 99.5 % (월 다운타임 ≤ 3.6 시간) |
| 장애 복구 목표 시간 (RTO) | ≤ 15 분 |

### 접근성 (Accessibility)

| 항목 | 기준값 |
|------|--------|
| 웹 접근성 표준 준수 | WCAG 2.1 Level AA 자동 감사 위반 0 건 |
| 키보드 전용 조작 | 핵심 5개 기능 키보드만으로 100 % 완수 가능 |
