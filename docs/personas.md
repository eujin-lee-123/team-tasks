# Team-Tasks 페르소나

> MVP 헌장: 단일 테이블 · 기능 5개 이하 · 1일 안에 코드로 옮길 수 있는 분량

| 역할 | 기술 수준 | 주요 시나리오 1 | 주요 시나리오 2 | 주요 시나리오 3 |
|------|-----------|----------------|----------------|----------------|
| **팀장 (매니저)** | 비개발 · 도구 사용에 익숙함 | 새 일감을 생성하고 담당자·마감일을 지정한다 | 전체 일감 목록을 보며 진행 상태(할 일 / 진행 중 / 완료)를 한눈에 파악한다 | 지연된 일감을 필터링해 담당자에게 우선순위를 재조정해 달라고 요청한다 |
| **팀원 (실무자)** | 개발자 · CLI·웹 모두 능숙 | 자신에게 할당된 일감 목록만 골라 오늘 해야 할 작업을 확인한다 | 일감 상태를 '진행 중'으로 바꾸고, 완료 시 '완료'로 업데이트한다 | 일감에 간단한 메모(진행 내용·블로커)를 남겨 팀장과 공유한다 |
| **관찰자 (이해관계자)** | 비개발 · 열람 전용 | 전체 일감 현황 대시보드를 읽기 전용으로 열람해 프로젝트 진행률을 확인한다 | 특정 팀원의 일감 부하를 파악해 리소스 배분 논의 자료로 활용한다 | 완료된 일감 이력을 날짜순으로 조회해 스프린트 회고 자료를 준비한다 |
